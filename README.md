## 设立宗旨

社交平台的推流算法永远偏爱大 V、情绪争议与公关营销。然而真正写出高质量代码、打磨极简工具、记录真实踩坑的扫地僧，往往只有几百到几千粉丝。

宝藏极客（Hidden Gems）专门记录全网被严重低估的建造者：
1. 不看粉丝基数：只看代码品味、信息信噪比与真实产品交付能力；
2. 挖掘小众项目：收录小而美、自给自足、架构克制的微工具与独立站点；
3. 为用心做事的人建立长期连接：帮助优质开发者突破算法信息茧房。

## 收录推荐标准

欢迎在 [Issues](https://github.com/realchendahuang/hidden-gems/issues) 提交你挖掘到的宝藏极客或自荐。

收录准则：
- 粉丝量不限，优先挖掘粉丝低于 1 万但技术信噪比极高的一线建造者；
- 个人主页或 GitHub 必须有真实、可运行的原创项目；
- 坚决过滤矩阵营销号、代运营号与纯转发生意号。
