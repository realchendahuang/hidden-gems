## 🎯 设立宗旨

主流社交算法永远推流大 V、争议言论与营销公关，而真正埋头写高质量代码、深耕小众极简工具、记录真实工程踩坑的扫地僧往往只有几百到几千关注。

**宝藏极客（Hidden Gems）** 专门挖掘和记录全网被严重低估的建造者：
- **不看粉丝量**：只看内容信噪比、代码品味与真实交付能力；
- **收录宝藏个人项目**：小而美、自给自足、架构优雅的小众工具与独立站点；
- **长期维护目录**：让用心做产品的人被看见、被连接。

---

## 💎 收录维度

1. **开发者画像**：个人简介、推特 ID、GitHub 地址、独立博客；
2. **代表作与代码库**：他做过什么令人眼前一亮的微工具或核心开源；
3. **推荐理由**：为什么他值得你加入常驻关注列表。
